# Скрипт Google Apps Script для Ozon Seller API

Этот скрипт позволяет автоматически загружать данные о товарах из Ozon Seller API в Google Таблицы.

## Возможности

- ✅ Получение списка всех товаров
- ✅ Получение остатков товаров (FBO и FBS)
- ✅ Получение цен товаров (включая старую цену, рекомендованную, минимальную и маркетинговую)
- ✅ Автоматическая пагинация для больших объемов данных
- ✅ Обновление остатков и цен в существующих таблицах
- ✅ Использование самых актуальных версий API:
  - **V3** для списка товаров
  - **V4** для остатков
  - **V5** для цен

## Установка

### Шаг 1: Создайте Google Таблицу

1. Откройте [Google Таблицы](https://sheets.google.com)
2. Создайте новую таблицу или откройте существующую

### Шаг 2: Откройте редактор Apps Script

1. В меню выберите **Расширения** → **Apps Script**
2. Удалите весь код в редакторе (если есть)
3. Скопируйте и вставьте код из файла `OzonSellerScript.gs`
4. Нажмите **Сохранить** (иконка дискеты или Ctrl+S)
5. Дайте проекту имя, например "Ozon Seller Integration"

### Шаг 3: Получите API ключи

Для работы со скриптом вам понадобятся **Client-ID** и **API-Key** от Ozon Seller:

1. Войдите в [Личный кабинет Ozon Seller](https://seller.ozon.ru/)
2. Перейдите в **Настройки** → **API ключи**
3. Создайте новый API ключ или используйте существующий
4. Скопируйте **Client-ID** и **API-Key**

### Шаг 4: Настройте API ключи в скрипте

1. Перезагрузите Google Таблицу
2. В меню появится новый пункт **Ozon Seller**
3. Выберите **Ozon Seller** → **⚙️ Настроить API ключи**
4. Введите ваш **Client-ID**
5. Введите ваш **API-Key**

> **Важно:** API ключи сохраняются безопасно в свойствах проекта и не будут видны другим пользователям.

## Использование

### Загрузить все товары

**Меню:** Ozon Seller → 📦 Загрузить все товары

Загружает базовую информацию о товарах:
- Product ID
- Offer ID
- Статус архивации
- Наличие остатков FBO
- Наличие остатков FBS
- Наличие скидки

**Результат:** Создается лист "Товары" с данными.

### Загрузить товары с остатками и ценами

**Меню:** Ozon Seller → 📊 Загрузить товары с остатками и ценами

Загружает полную информацию о товарах:
- Product ID
- Offer ID
- Статус товара
- Остаток FBO
- Остаток FBS
- Цена
- Старая цена
- Цена с премиум
- Рекомендованная цена
- Минимальная цена
- Маркетинговая цена
- Маркетинговая акция

**Результат:** Создается лист "Товары (полные данные)" с данными.

> **Примечание:** Этот процесс может занять несколько минут, если у вас много товаров.

### Обновить остатки

**Меню:** Ozon Seller → 🔄 Обновить остатки

Обновляет только остатки товаров в текущем листе. Лист должен содержать столбцы:
- Product ID
- FBO остаток
- FBS остаток

### Обновить цены

**Меню:** Ozon Seller → 💰 Обновить цены

Обновляет только цены товаров в текущем листе. Лист должен содержать столбец:
- Product ID
- Цена

И опционально:
- Старая цена
- Цена с премиум
- Рекомендованная цена
- Минимальная цена
- Маркетинговая цена

### Очистить лист

**Меню:** Ozon Seller → 🗑️ Очистить лист

Полностью очищает текущий лист.

## Структура данных

### Типы цен в Ozon

| Тип цены | Описание |
|----------|----------|
| **Цена** | Текущая цена товара |
| **Старая цена** | Зачеркнутая цена (показывается как "было") |
| **Цена с премиум** | Цена для подписчиков Ozon Premium |
| **Рекомендованная цена** | Рекомендация от Ozon для конкурентной цены |
| **Минимальная цена** | Минимально возможная цена товара |
| **Маркетинговая цена** | Цена участия в маркетинговых акциях |

### Типы остатков

| Тип | Описание |
|-----|----------|
| **FBO** | Fulfillment by Ozon - товары на складе Ozon |
| **FBS** | Fulfillment by Seller - товары на вашем складе |

## Технические детали

### Используемые версии API

Скрипт использует самые актуальные версии Ozon Seller API:

1. **V3 Product List** (`/v3/product/list`)
   - Получение списка товаров
   - Поддержка фильтров по visibility
   - Пагинация через last_id

2. **V4 Product Info Stocks** (`/v4/product/info/stocks`)
   - Получение остатков товаров
   - Раздельные данные по FBO и FBS
   - Курсорная пагинация

3. **V5 Product Info Prices** (`/v5/product/info/prices`)
   - Получение всех типов цен
   - Самая новая версия API
   - Курсорная пагинация

### Лимиты и ограничения

- **Максимальное количество товаров в одном запросе:** 1000
- **Батчинг:** Запросы разбиваются на батчи по 100 товаров для избежания таймаутов
- **Rate limiting:** Между запросами установлены задержки (500мс - 1с)
- **Timeout Google Apps Script:** ~6 минут для одного выполнения

> **Совет:** Если у вас очень большой каталог (>10,000 товаров), используйте функцию загрузки несколько раз с фильтрами.

### Фильтры visibility

Доступные значения для фильтрации товаров:

```javascript
VISIBILITY.ALL                 // Все товары
VISIBILITY.VISIBLE             // Видимые для покупателей
VISIBILITY.INVISIBLE           // Невидимые для покупателей
VISIBILITY.EMPTY_STOCK         // Товары без остатка
VISIBILITY.IN_SALE             // В продаже
VISIBILITY.REMOVED_FROM_SALE   // Удалено из продажи
VISIBILITY.ARCHIVED            // В архиве
```

По умолчанию используется `VISIBILITY.ALL`.

## Автоматизация

### Настройка автоматического обновления

Вы можете настроить автоматическое обновление данных по расписанию:

1. В редакторе Apps Script выберите **Триггеры** (иконка будильника слева)
2. Нажмите **+ Добавить триггер**
3. Выберите функцию: `loadProductsWithStocksAndPrices`
4. Выберите тип триггера: **Временный**
5. Выберите интервал (например, раз в день, раз в час)
6. Нажмите **Сохранить**

> **Примечание:** При первом запуске триггера может потребоваться авторизация.

### Пример кастомной функции для фильтрации

Вы можете создать свои функции для загрузки только нужных товаров:

```javascript
function loadOnlyInSaleProducts() {
  var products = getAllProducts({ visibility: VISIBILITY.IN_SALE });
  // ... ваш код обработки
}
```

## Устранение неполадок

### Ошибка: "API учетные данные не настроены"

**Решение:** Используйте меню **Ozon Seller** → **Настроить API ключи** и введите ваши Client-ID и API-Key.

### Ошибка: "Ошибка API: 401"

**Причина:** Неверные Client-ID или API-Key.

**Решение:**
1. Проверьте правильность ключей в личном кабинете Ozon
2. Пересохраните ключи через меню настроек

### Ошибка: "Ошибка API: 403"

**Причина:** Недостаточно прав у API ключа.

**Решение:** Создайте новый API ключ с полными правами в личном кабинете Ozon Seller.

### Ошибка: "Превышено время выполнения"

**Причина:** Слишком много товаров для загрузки за один раз (ограничение Google Apps Script ~6 минут).

**Решение:**
1. Используйте фильтры для загрузки меньшего количества товаров
2. Разбейте загрузку на несколько этапов
3. Рассмотрите использование Google Apps Script с платным аккаунтом (увеличенные лимиты)

### Товары загружаются, но нет остатков или цен

**Причина:** Товары могут быть архивированы или у них не настроены цены.

**Решение:** Проверьте статус товаров в столбце "Статус" и убедитесь, что товары активны в личном кабинете Ozon.
